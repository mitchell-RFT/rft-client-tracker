5-minute setup:
1. Create a free account at airtable.com
2. Create a Base called RFT Clients and a Table called Clients
3. Add these fields to the table:
  Name · Phone · Email · Category (Single select) · Service · Price (Number) · Contract (Single select)
4. Go to airtable.com/create/tokens → create a token with data.records:read + data.records:write scopes
5. Your Base ID is in the URL: airtable.com/appXXXXXXXX/…
